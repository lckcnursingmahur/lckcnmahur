# Late Chandrabhagabai Keshave College of Nursing (GNM)

A responsive college website starter for Mahur, Maharashtra.

## Open locally
Open `index.html` in any modern web browser.

## Customize
- Replace the gallery placeholders with real college photographs.
- Add phone/email details in `index.html`.
- Replace the LC circle with the official college logo.
- Add official admission eligibility, fees, affiliation, notices and faculty details after verification.
